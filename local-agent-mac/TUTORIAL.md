# SmartMarker 过关单批改 — 使用教程

## 快速开始

### 第一步：打开 App，输入邀请码

1. 双击打开 SmartMarker.app
2. 首次使用会弹出配置窗口
3. 输入邀请码（找管理员获取）
4. 授权目录可选填（用于本地文件操作，批改功能不需要）
5. 点击 **"开始使用"**

### 第二步：上传标准答案

1. 点击输入框左侧的 **📎 附件按钮**
2. 选择标准答案的照片（支持 1-3 页，JPG/PNG）
3. 在输入框输入 **"这是标准答案"** 或 **"批改过关单"**
4. 点击发送

> 📸 拍照建议：平放纸张，光线均匀，避免手指遮挡。

系统会自动识别每道题的正确答案，大约 10 秒后返回预览：

```
✅ 答案已识别，共 100 题（3 页）。

  #1: deep  #2: desert  #3: Asia  #4: feel free to ...

⚠️ 以下 2 题识别可能有误，请重点检查：
  #47: 当前识别为 "mobile"（置信度低）

确认无误请说"没问题"。如需修正，输入如 "47:movable" 即可。
```

### 第三步：确认或修正答案

- **没问题？** → 直接输入 `没问题` 发送
- **要修正？** → 输入 `47:movable` 发送（题号:正确答案）
- **多题修正？** → 输入 `47:movable 63:separate` 一次修正多题

### 第四步：上传学生答卷

1. 再次点击 📎 附件按钮
2. **按顺序** 选择学生答卷照片：
   - 学生1第1页 → 学生1第2页 → 学生1第3页 → 学生2第1页 → ...
3. 输入 **"开始批改"** 或 **"批改"**
4. 点击发送

> ⚠️ 照片必须按学生分组排列，每个学生的页数要与标准答案一致。
> 例如：答案有 3 页，则每 3 张照片为一个学生。

### 第五步：等待批改结果

系统会逐个学生批改，显示实时进度：

```
批改中 12/28（约剩 45 秒）
```

完成后显示摘要：

```
✅ 批改完成！共 28 位学生

📊 班级概况：平均 76.2% | 最高 98% 张三 | 最低 52% 王五
📌 高频错题：#7 take a taxi（错误率 60%）、#11 See you then（50%）

[下载 Excel]  [下载 CSV]
```

### 第六步：下载报告

点击 **"下载 Excel"** 按钮，打开 4 个 Sheet 的完整报告：

| Sheet | 内容 |
|-------|------|
| 成绩总览 | 每个学生的正确/错误/得分率/排名 |
| 逐题矩阵 | 每个学生每道题的对错情况 |
| 错题统计 | 每道题的错误率、常见错误答案、知识点 |
| 逐人反馈卡 | 可复制发给家长的个人反馈文本 |

## 进阶用法

### 追加批改

第一批学生批改完成后，可以继续上传更多学生：

1. 上传新的学生答卷照片
2. 输入 "批改" 或 "追加"
3. 系统自动追加到已有结果中

### 查看历史答案

输入 **"使用之前的答案"**，系统会列出已保存的答案列表，选择编号即可复用，无需重新上传。

### 低置信度复核

如果系统对某些 OCR 结果不确定，会提示：

```
⚠️ 3 道题需要你确认（OCR 不确定）
  回复"查看确认题"可逐条复核
```

输入 **"查看确认题"**，然后回复需要改判为正确的题号（如 `1 3`）。

## 常见问题

**Q: 识别结果不准怎么办？**
A: 重新拍摄更清晰的照片，或手动修正（`题号:正确答案`）。

**Q: 照片顺序搞错了怎么办？**
A: 输入 "重新批改"，重新上传照片。

**Q: 支持哪些题型？**
A: 目前支持填空题（英语词汇、短语、句型）。选择题、判断题也可以，只要答案能被 OCR 识别。

**Q: 一次最多批改多少学生？**
A: 无硬性限制，60 人约需 3 分钟。建议每次不超过 100 人。
