# SmartMarker 过关单批改 — 使用教程

---

## 一、服务器管理员：配置 API Key

> 如果你是测试用户（不管服务器），跳到「二、安装 App」。

过关单批改依赖阿里云百炼平台的视觉模型（qwen-vl-plus），需要配置 API Key 才能使用图片识别功能。

### 1. 获取阿里云百炼 API Key

1. 打开 [百炼控制台](https://bailian.console.aliyun.com/)，用阿里云账号登录
2. 左侧菜单点击 **「API-KEY 管理」**
3. 点击 **「创建新的 API-KEY」**，选择默认业务空间
4. 复制生成的 `sk-xxxxxxxx` 密钥

### 2. 开通 qwen-vl-plus 模型

1. 在百炼控制台左侧点击 **「模型广场」**
2. 搜索 `qwen-vl-plus`
3. 点击进入模型详情页，点击 **「开通」**（按量付费，开通免费，调用才计费）
4. 费用参考：批改 60 个学生约 ¥3

### 3. 配置服务器 .env

在服务器上编辑 `.env` 文件：

```bash
ssh your-server
cd /path/to/SmartMarker
cp .env.example .env    # 首次才需要
nano .env               # 编辑
```

修改以下三行：

```
ALI_MODEL_ENDPOINT=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
ALI_API_KEY=sk-你复制的API密钥
ALI_VLM_MODEL=qwen-vl-plus
```

确保 `MOCK_MODE` 设为 `false`（或删掉这行）：

```
MOCK_MODE=false
```

### 4. 重启服务

```bash
docker compose up -d --build
```

### 5. 验证 API 是否可用

```bash
curl -s https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的密钥" \
  -d '{"model":"qwen-vl-plus","messages":[{"role":"user","content":[{"type":"text","text":"回复OK"}]}],"max_tokens":10}'
```

看到 `"content":"OK"` 就说明配置成功。如果看到 `AccessDenied.Unpurchased`，说明模型没开通（回到第 2 步）。

### 6. 创建邀请码给老师

```bash
curl -X POST "http://你的服务器IP:8080/admin/invites" \
  -H "x-admin-key: 你的ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code":"TEACHER-ZHANG","max_uses":1}'
```

把邀请码 `TEACHER-ZHANG` 发给老师即可。

## 二、安装 App

### macOS

1. 双击 `SmartMarker.dmg`
2. 把 SmartMarker 拖到 Applications 文件夹
3. **首次打开会被系统拦截**（因为没有 Apple 签名），解决方法：
   - 方法 A：右键点击 SmartMarker.app → 选择 **"打开"** → 弹窗中点 **"打开"**
   - 方法 B：打开 **系统设置 → 隐私与安全性** → 底部找到 SmartMarker → 点击 **"仍要打开"**

### 首次配置

1. 打开 App，看到「首次配置」窗口
2. **邀请码**：输入管理员给你的邀请码（如 `TEACHER-ZHANG`）
3. **授权目录**：可选，如果不需要本地文件操作可以跳过
4. 点击 **"开始使用"**

配置成功后，后续打开 App 会自动连接，不需要再输入邀请码。

## 三、批改过关单：完整步骤

### 第 1 步：拍摄标准答案

用手机拍摄标准答案纸张的照片，传到电脑上。

> **拍照要求**：
> - 纸张平放，不要歪斜
> - 光线均匀，不要有阴影遮挡
> - 文字清晰可读
> - 每页拍一张照片（如果答案有多页，拍多张）

### 第 2 步：上传标准答案

1. 在 App 聊天界面，点击输入框左边的 **📎 按钮**（或「选择文件」）
2. 选择标准答案的照片（可以一次选多张）
3. 在输入框输入：**这是标准答案**
4. 点击发送

等待约 10 秒，系统会返回识别结果：

```
✅ 答案已识别，共 100 题（3 页）。

  #1: deep  #2: desert  #3: Asia  #4: feel free to ...

⚠️ 以下 2 题识别可能有误，请重点检查：
  #47: 当前识别为 "mobile"（置信度低）
  #63: 当前识别为 "complete"（置信度低）

确认无误请说"没问题"。如需修正，输入如 "47:movable" 即可。
```

### 第 3 步：检查并确认答案

看一下识别的答案对不对：

- **都对了** → 输入 `没问题`，回车
- **有一题要改** → 输入 `47:movable`，回车（格式是 `题号:正确答案`）
- **要改好几题** → 输入 `47:movable 63:complete 91:government`，一次改完
- **改完后** → 再输入 `没问题` 确认

### 第 4 步：拍摄学生答卷

用手机拍摄学生的答卷照片，传到电脑上。

> **重要：照片必须按顺序排列！**
>
> 如果标准答案是 3 页，那每个学生也是 3 页。照片排列方式：
> ```
> 学生1-第1页.jpg
> 学生1-第2页.jpg
> 学生1-第3页.jpg
> 学生2-第1页.jpg
> 学生2-第2页.jpg
> 学生2-第3页.jpg
> ...
> ```
>
> 简单说就是：**一个学生拍完再拍下一个，别混着来。**

### 第 5 步：上传学生答卷并开始批改

1. 点击 📎 按钮，选择所有学生答卷照片
2. 在输入框输入：**开始批改**
3. 点击发送

系统会提示照片数量和估算学生数：
```
已收到 90 张照片（约 30 份答卷，每份 3 页）
```

如果张数不是整数倍，系统会提醒你检查是否遗漏了照片。

### 第 6 步：等待批改

批改过程中会显示进度：
```
批改中 12/30（约剩 50 秒）
```

30 个学生大概需要 1-2 分钟。

### 第 7 步：查看结果

批改完成后，系统显示摘要：

```
✅ 批改完成！共 30 位学生

📊 班级概况：平均 76.2% | 最高 98% 张三 | 最低 52% 王五
📌 高频错题：#7 take a taxi（错误率 60%）、#11 See you then（50%）
⚠️ 3 道题需要你确认（OCR 不确定）

[下载 Excel]  [下载 CSV]
```

### 第 8 步：下载 Excel 报告

点击 **"下载 Excel"**，用 WPS 或 Excel 打开，里面有 4 个表：

| 表名 | 内容 | 用途 |
|------|------|------|
| **成绩总览** | 每个学生的正确数、错误数、得分率、排名 | 登记成绩 |
| **逐题矩阵** | 每个学生每道题的对错（✓ 或错误答案） | 找出个别学生的薄弱点 |
| **错题统计** | 每道题的错误率、知识点、常见错误答案 | 调整教学重点 |
| **逐人反馈卡** | 每个学生的错题列表，可复制发家长 | 家校沟通 |

## 四、更多用法

### 批改更多学生（追加模式）

第一批批改完后，还有更多学生要批改？

1. 上传新的学生答卷照片
2. 输入 **"继续批改"** 或 **"追加"**
3. 系统会自动追加到已有结果中，Excel 里会包含所有学生

### 换一套答案

输入 **"换一套答案"**，然后上传新的标准答案照片，从头来过。

### 复用之前的答案

如果之前已经录入过答案（比如上周的过关单），不需要重新拍照：

1. 输入 **"使用之前的答案"**
2. 系统列出你保存过的答案，输入序号选择
3. 直接上传学生答卷开始批改

### OCR 不确定的题怎么处理

如果系统提示有 OCR 不确定的题：

1. 输入 **"查看确认题"**
2. 系统列出所有不确定的题目，例如：
   ```
   1. 张三 #47: OCR 读到 "achive" → 正确答案 "achieve"
   2. 李四 #63: OCR 读到 "seperate" → 正确答案 "separate"
   3. 王五 #91: OCR 读到 "goverment" → 正确答案 "government"

   回复题号表示"其实写对了"，或说"全部错"。
   ```
3. 如果 1 和 3 其实写对了（只是拼写和标准答案很接近），输入 `1 3`
4. 如果确实都错了，输入 **"全部错"**

## 五、常见问题

**Q: 识别不准怎么办？**

A: 照片越清晰识别越准。如果某道题识别错了，直接用 `题号:正确答案` 修正。如果大面积不准，建议重新拍照（光线更好、距离更近）。

**Q: 照片顺序搞错了怎么办？**

A: 输入 **"重新批改"**，然后按正确顺序重新上传照片。

**Q: 支持什么类型的题？**

A: 主要支持英语过关单（词汇填空、短语、句型）。选择题、判断题也能用，只要学生写在纸上的答案能被拍照识别。

**Q: 一次能批改多少学生？**

A: 没有硬性限制。60 人大约 3 分钟，建议每次不超过 100 人。

**Q: App 打不开 / 闪退怎么办？**

A:
1. 确认用的是「右键 → 打开」方式（不是双击）
2. 如果提示"已损坏"，在终端执行：`xattr -cr /Applications/SmartMarker.app`
3. 如果仍有问题，联系管理员确认服务器是否在运行

**Q: 提示"模型调用失败"怎么办？**

A: 联系管理员检查服务器的 API Key 是否有效，以及 qwen-vl-plus 模型是否已开通。

## 六、服务器管理员：API Key 失效后如何更换

API Key 可能因欠费、过期等原因失效。更换方法：

### 1. 获取新 Key

登录 [百炼控制台](https://bailian.console.aliyun.com/) → API-KEY 管理 → 创建新 Key

### 2. 更新服务器配置

```bash
ssh your-server
cd /path/to/SmartMarker
nano .env
```

把 `ALI_API_KEY=` 后面的值换成新 Key：

```
ALI_API_KEY=sk-新的密钥
```

### 3. 重启服务

```bash
docker compose restart orchestrator
```

无需重启 App，老师那边不受影响（App 连的是服务器，不直接调 API）。

### 4. 验证

```bash
curl -s http://127.0.0.1:8080/chat \
  -H "Authorization: Bearer 你的JWT" \
  -H "Content-Type: application/json" \
  -d '{"message":"批改过关单"}'
```

看到引导文案就说明恢复正常了。
